# Northline

Demo marketing website for **Northline**, a fictional performance advertising agency.

The site promotes paid media services with sample client outcomes, revenue metrics, and a consultation inquiry form.

## Preview

Open `index.html` in your browser, or serve the folder locally:

```bash
npx serve .
```

## What’s included

- Full-bleed hero with brand-forward composition
- Animated revenue / ROAS outcome metrics
- Four fictional case studies (Meridian Retail, Atlas Fitness, Harbor Home Goods, Lumina Beauty)
- Services, approach, leadership, and contact sections
- Scroll reveals, counter animations, and responsive navigation

## Note

Client names, photos, and performance figures are fictional and for demonstration only.
